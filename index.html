🏋️ Gym Progress

Track your workouts. Monitor your progress. Keep your data safe.

About

Gym Progress is a mobile fitness application that helps users record workouts, track exercise performance, and monitor progress over time.

All workout data is stored locally on your device using SQLite. Users can optionally enable secure cloud backups using their own Google Drive account, allowing seamless data restoration when changing devices or reinstalling the application.

Features

  • 🏋️ Record workout results
  • 📈 Progress charts and statistics
  • 📅 Workout history
  • 💪 Personal exercise library
  • 📱 Local SQLite database
  • ☁️ Secure Google Drive backups
  • 🔄 Automatic cloud synchronization (optional)

Privacy

Your workout data belongs only to you.

Gym Progress does not collect, store, or access your workout history.

When cloud backup is enabled, backup files are stored only in your private Google Drive AppData folder. The developer cannot access, read, or modify these files.

Google Sign-In

Google Sign-In is used exclusively to:

  • Authenticate your Google account.
  • Create and update backup files.
  • Restore backup data.
  • Delete backup files if requested.

The application never accesses other files stored in your Google Drive.

Technologies

  • React Native
  • Expo
  • SQLite
  • Google Sign-In
  • Google Drive AppData API
